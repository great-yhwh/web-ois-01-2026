# web-ois-01-2026
Web-ориентированные информационные системы

Домашняя работа 2.

В рамках работы реализовано:
1. CRUD для клубов (`/api/clubs`):
    - `POST /api/clubs` — создание клуба 
      (уникальность названия без учёта регистра `409`, 
      тримминг пробелов, валидация 2–100 символов `422`, 
      статус `201`).
    - `PATCH /api/clubs/{club_id}` — переименование клуба 
      (проверка на занятое название `409`, `404` если не найден,
      статус `200`).
    - `DELETE /api/clubs/{club_id}` — удаление клуба 
      (запрет удаления при наличии привязанных мероприятий
      с указанием их количества `409`, `404` если не найден, 
      статус `204`).
2. Фильтрация и поиск мероприятий (`GET /api/events`):
    - Параметр `room_id` — фильтр по аудитории.
    - Параметр `q` — поиск по подстроке в названии без 
      учёта регистра (длина от 2 до 50 символов, короче 2 — `422`).
    - Фильтры корректно сочетаются друг с другом
      и с пагинацией, поле `total` пересчитывается.
3. Документация и автотесты:
    - Swagger (`/docs`): описания, summary,
      примеры (`examples`) и схема `ErrorResponse` 
      для кодов 404/409.
    - [Коллекция](postman/web-ois-hw02.postman_collection.json) Postman с полным набором интеграционных тестов.
